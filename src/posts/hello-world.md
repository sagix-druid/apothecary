This is a sample post. If you can read it at http://localhost:8080/hello-world/, the starter works.

Delete `src/posts/hello-world.md` and `src/pages/about.md` before you run `npm run import`, so the sample doesn't sit among your real posts.

The Ghost import writes one Markdown file per post into `src/posts/`, and the file name is the post's web address.
