<h2>About Arbitrum</h2>
<p>Arbitrum, developed by Offchain Labs and launched in 2021, is a leading Ethereum Layer 2 scaling solution using Optimistic Rollups. It processes transactions off-chain with Ethereum mainnet security, achieving ~4,000-7,000 TPS and fees of ~$0.01–0.1 USD (paid in ETH). Arbitrum One, its primary chain, hosts ~$3B in TVL across DeFi protocols like GMX and SushiSwap. The ARB token, launched in 2023 with a 10B token cap, powers decentralized governance via the Arbitrum DAO, enabling holders to vote on protocol upgrades and ecosystem funding.</p>

          changeElement.style.color = change7d > 0 ? '#22c55e' : '#ef4444';
        } else {
          changeElement.textContent = 'Change unavailable';

        var marketCap = data.market_data.market_cap.usd;
