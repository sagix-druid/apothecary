Aave is a decentralized finance (DeFi) protocol that enables users to lend and borrow cryptocurrencies in a permissionless, non-custodial manner without relying on intermediaries like banks. It operates primarily on the Ethereum blockchain but has expanded to multiple networks, allowing participants to supply assets to liquidity pools and earn interest, or borrow against collateral with variable or stable interest rates.

Aave has become one of the largest DeFi platforms by total value locked (TVL), promoting financial inclusion by making lending and borrowing accessible globally via a wallet connection. However, like all DeFi protocols, it carries risks such as smart contract vulnerabilities, market volatility, and liquidation events. Always conduct your own research before using it.

<h2>About AAVE</h2>
<p>AAVE, originally launched as ETHLend in 2017 and rebranded in 2020, revolutionized decentralized lending by introducing algorithmic interest rates, flash loans, and over-collateralized borrowing without credit checks. The protocol operates across multiple blockchains including Ethereum, Polygon, Avalanche, Arbitrum, and Optimism, with combined TVL exceeding $10 billion. AAVE tokens (capped at 16M supply) serve dual purposes: governance over protocol parameters and staking in the Safety Module, which acts as an insurance fund protecting depositors while rewarding stakers with 7-10% APR. The protocol generates revenue through borrowing interest and flash loan fees, with governance deciding on treasury management and protocol upgrades through decentralized voting.</p>

  function generateSparklineSVG(prices, width, height, strokeColor) {
    if (!prices || prices.length < 2) {
      return '<svg width="' + width + '" height="' + height + '"></svg>';
    }
    var minPrice = Math.min.apply(Math, prices);
    var maxPrice = Math.max.apply(Math, prices);
    var priceRange = maxPrice - minPrice || 1;
    var points = prices.map(function(price, i) {
      var x = (i / (prices.length - 1)) * width;
      var y = height - ((price - minPrice) / priceRange) * height;
      return x + ',' + y;
    }).join(' ');
    return '<svg width="' + width + '" height="' + height + '" viewBox="0 0 ' + width + ' ' + height + '" xmlns="http://www.w3.org/2000/svg"><polyline fill="none" stroke="' + strokeColor + '" stroke-width="2" points="' + points + '" /></svg>';
  }
